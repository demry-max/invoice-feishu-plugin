## 一、概览

本轮迭代覆盖了**账单计算逻辑**、**输出文档质量**、**插件操作流程**三大块。共 13 个 PR，跨 7 次需求迭代。所有改动均已部署到飞书新 App（`cli_a977c45068391cb6`）以及后端 `https://invoice-api.gdsgroup.tech`。

**最大体感变化**：
- 顾问账单 + 尾款账单两种独立模板，各有专属字段与计算公式
- 生成的 PDF 显著更"像专业财务系统出的"
- 同一工单重新生成账单，编号不变（覆盖式更新）
- 插件界面从冗长滚动改为单屏可见，主按钮永远粘底
- 财务每天用的设置会被记住，下次自动恢复

## 二、按主题列出全部改动

### 1. 账单类型重构

#### 1.1 新增"账单类型"切换
- 顶部一键切换 **顾问账单 / 尾款账单**，两种类型走完全不同的计算与排版

#### 1.2 顾问账单
- 税率比例可选：1% / 3% / 6% / 12%
- 预扣税比例（EWT）可选：2% / 10% / 15%
  - 仅**星耀财税 / Star Shine Taxation**模板需要计算 EWT
  - **菲龙咨询 / Feilong Consulting**模板不计 EWT
- 含税模式 toggle：
  - **不含税**：账单总计仅显示 Total 和 Grand Total（相等），无 VAT / EWT 行
  - **含税**：按所选比例计算 VAT 和 EWT
- 计算公式（含税模式）：
  ```
  税前小计 = Σ(line_total，仅 Taxation Identification = YES 的行)
  VAT 金额 = 税前小计 × VAT 税率
  EWT 金额 = 税前小计 × EWT 税率（仅 Starlight）
  合计 = 总小计 + VAT − EWT
  ```
- 非应税行（Taxation Identification ≠ YES）依然展示在账单上，只是不参与税费计算
- 折扣列：当所有行 Discount 为 0 / null / `-` 时**整列自动隐藏**

#### 1.3 尾款账单（按"最终账单插件需求"独立模板）
- 表头改为 8 列：Bill Number / Date / Product/Service / Amount Billed / Actual Amount Incurred / Amount Paid / Balance / Note
- 表底自动 Grand Total 行
- 总计区只展示：
  - Total Balance = Σ(Actual − Paid)
  - Amount Refunded（仅在 > 0 时显示）
  - Final Balance = Total Balance + Amount Refunded
  - **不展示 Deductible Amount**
- 顶部抬头：Client Name + Client Company（自动从工单主表读取）

### 2. 币种与汇率换算

#### 2.1 展示币种选择
- 尾款账单可选 **原始 / CNY / USD / PHP**
- 选"原始"时按业务工单的源币种展示，不换算

#### 2.2 双汇率独立处理
- **Bill Currency → 展示币种** 用于：Amount Billed / Paid / Refunded / Deductible
- **Final bill currency → 展示币种** 用于：Actual Amount Incurred
- 各自独立查表，独立换算

#### 2.3 汇率表查找规则
- 在【汇率表 / Exchange Rate Table】中匹配：
  - `Original currency` = 源币种
  - `Target currency` = 展示币种
  - 账单日期 ∈ [`Effective Date`, `Expiry Date`]
- 找不到匹配 → 顶部黄色警告条 + 按 1:1 处理

#### 2.4 重复字段诊断
- 展示币种选择面板下方实时显示两条汇率信息：
  - `Bill rate: 1 CNY = 8.3 PHP`
  - `Final rate: 1 PHP = 1 PHP`（自适配，若一致则提示无需换算）

### 3. 数据回调（写回业务工单）

#### 3.1 顾问账单生成后自动写回
- `Bill Number` = 账单编号
- `Billing Date` = 账单日期（毫秒时间戳，飞书 Date 字段需要）
- `HTML link` / `PDF link`
- `Add:VAT(x%)` = VAT 金额
- `Less:EWT(2%)` = EWT 金额

#### 3.2 尾款账单生成后自动写回
- `Final Billing Number`
- `Final Billing Date`
- `Final HTML link` / `Final PDF link`
- `Final Balance`
- `Display Currency`（用户选的展示币种）

#### 3.3 重新生成保持原编号
- 对同一工单**重新生成同类型账单**时，自动复用原账单号
- HTML 与 PDF 内容更新覆盖
- 顾问与尾款各自独立编号（同一 WO 可有 1 张顾问 + 1 张尾款）

#### 3.4 编号起点
- 2026 年 5 月起从 `202605-12796` 开始（财务对账要求）

### 4. UI / 操作流程升级（Sprint A）

#### 4.1 顶部状态条（合并三个 section）
- 旧版：选中记录 / 重复提示 / 账单类型 三个独立 section 占满一屏
- 新版：单行 sticky 状态条，包含：
  - 工单客户摘要：`广州跃播 · 3 项`
  - 顾问 / 尾款分段控件
  - `✓ 复用编号 202605-12796` 绿色徽章（已有账单时）
  - 重新加载按钮 ⟳

#### 4.2 客户信息折叠
- 默认显示单行摘要：`公司名 · 联系人 · 日期`
- 点"编辑"展开详细表单

#### 4.3 账单设置折叠
- 默认显示芯片摘要：`菲龙咨询 · 含税 6% · EWT 2%`
- 点"展开"显示完整控件矩阵
- 设置变动后摘要实时更新

#### 4.4 底部 Sticky 操作条
- 永远可见的工具栏，左侧实时 Grand Total，右侧主按钮
- 按钮文字会自适应：
  - 新生成：`生成正式账单`

#### 4.5 ⌘+Enter (Mac) / Ctrl+Enter 快捷键
- 一键生成账单（满足预览和必填校验后）

### 9. 底层稳定性 / 修复

#### 9.1 SQLite 持久化
- 所有账单数据存到本地 SQLite，容器重启不会丢
- HTML / PDF 文件落到挂载卷 `/opt/invoice-api/data`，跨重建保留

#### 9.2 账单编号不再撞号
- 容器重启后从数据库读取当月最大编号，避免与历史账单冲突
- 配合"重复生成保留原号"逻辑

#### 9.3 飞书 Date 字段写回兼容
- 飞书 Date 字段需要毫秒时间戳，不能写字符串
- 写回 Billing Date / Final Billing Date 自动转 ms

#### 9.4 汇率表日期匹配
- 飞书 Date 字段读出来是数字时间戳；插件自动转 `YYYY-MM-DD` 后再比较
- 修复了"汇率表中明明有数据却匹配不到"的旧 bug

#### 9.5 重复账单提示
- 工单已有账单时，顶部黄色"该工单已有 …"提示条
- 可点忽略；也可直接重新生成（自动覆盖）

#### 9.6 域名白名单 + blob 下载
- 客户端用 fetch + blob URL 触发 PDF 下载，绕过飞书域名拦截
- 同时新 App 已配置 `https://invoice-api.gdsgroup.tech` 为服务器域名白名单

## 三、给用户的简明使用提示

### 日常黄金路径（5 步）
1. **选中工单** —— 在多维表格点一行 WO
2. **切类型** —— 顶部点 `顾问账单` 或 `尾款账单`
3. **看顶部** —— 如果有 `✓ 复用编号 XXX` 绿色徽章，表示该工单已有同类账单，再生成会覆盖
4. **看底部** —— Grand Total 实时更新，确认无误
5. **生成** —— 点底部红色按钮 / 或按 `⌘+Enter`

### 常见操作
| 想做 | 怎么做 |
|---|---|
| 调整税率 | 点账单设置 `展开` → 选 VAT% |
| 调整 EWT | 同上，仅在 Starlight 模板下出现 |
| 换币种展示 | 切换到尾款账单 → 选 CNY / USD / PHP |
| 编辑客户信息 | 客户信息 `编辑` 展开输入框 |
| 看历史账单 | 顶部 `📚 该工单历史账单` 点开 |
| 重新生成（不换号）| 直接再点生成按钮，自动覆盖原号 |
| 下载 PDF | 生成后底部 `📥 下载 PDF` |
| 把 PDF 给客户 | 下载后附到邮件，或扫 QR 码分享 HTML |

### 报错怎么办
| 现象 | 原因 / 解决 |
|---|---|
| 顶部红色 ⛔ 请填写 Bill To | 客户信息 → 编辑 → 填 Bill To |
| 黄色 ⚠️ 所有行 Taxation Identification 都不为 YES | 任务明细表把要计税的行标 YES |
| 黄色 ⚠️ 汇率表中无 XXX→YYY 行 | 在汇率表添加包含当前账单日期的有效汇率 |
| Bitable 字段没读到 / 全空 | 检查表名 / 列名是否与文档一致；F12 看 Console |

### 重置个人设置
- 浏览器 Console 跑：`localStorage.clear()` → 刷新插件
- 或开新隐身窗口
